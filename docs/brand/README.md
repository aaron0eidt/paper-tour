# Brand

The Paper Tour mark is a gradient tile (`#7ea6ff` to `#8b5cf6`) holding a page with one sentence highlighted in
yellow (`#ffe45c`), the product's own highlight. It is set in Inter.

| File | Use |
|---|---|
| `banner.png` | The 1600 x 480 header at the top of the README. |
| `social-preview.png` | The 1280 x 640 social card. Upload it in the repository settings under Social preview. |
| `logo.svg`, `logo-512.png` | The detailed mark, for large sizes. |
| `wordmark-dark.svg`, `wordmark-light.svg` | The mark with "Paper Tour", for dark and for light backgrounds. The text is outlined, so no font is needed. |

The app uses the small-size drawing of the mark, which stays crisp from 14 to 48 px. It is the
`player/src/brand/BrandMark.tsx` component and the favicons in `player/src/brand/`.
