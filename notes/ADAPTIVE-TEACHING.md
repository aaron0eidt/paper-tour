# Adaptive teaching plans

New research-paper generations with a saved tour profile have a separate teaching-planning stage. It reads the complete paper text and uses a section-balanced vocabulary of citable sentences, equations and figures. Older queued jobs and saved tours keep their existing behavior.

The model separates contribution, prerequisite, mechanism, evidence and limitation. Each concept records source IDs, prerequisite IDs, importance, audience-relative difficulty, confidence, a learning objective, a possible misconception and the benefit of a visual. These are inspectable teaching decisions, not private model reasoning or claims about a particular reader.

Validation rejects nonexistent sources, cycles, duplicate concept IDs, missing section accounting and proposed new visuals without a stated relationship/change. One repair receives the exact problems; an invalid teaching map is never silently published as a valid plan.

The concept-led profile preserves the current narrative grammar and adds important concepts missed by the opening-claim extractor. Overview selects the main ideas and their necessary prerequisites. Paper order follows actual source locations and actual headings, rather than imposing an Abstract/Methods/Results template. Depth and audience remain independent of structure and provider model.

Visual planning receives these objectives. For new profile generations it chooses representations by usefulness instead of imposing the legacy per-kind and board-share quotas. Source annotation remains preferable when it explains the point directly. A numerical example should change visible inputs/intermediates/outputs; a caption or a decorative restatement is not a demonstration. Original values, source alignment and mathematical validation still apply.

The verified teaching map is saved with generation metadata. The activity feed exposes the planning stage with a readable label. It does not stream speculative reasoning.

Tests cover section-balanced sampling, source/dependency checks, prerequisite selection, true paper order, compatibility with the existing concept-led grammar and freedom to use an appropriate representation more than once.
